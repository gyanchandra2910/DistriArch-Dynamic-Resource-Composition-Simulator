GITHUB SOURCE CHECKOUT (WINDOWS)
The GitHub repository includes source and experiment data. Native binaries
and frontend/dist are generated locally and excluded from Git.
Install a C++20 GCC compiler with zlib, PowerShell, Node.js 22.12+ and
pnpm 11.25.0. Open PowerShell in this folder and run:
  .\launch.ps1 -Setup
Then open http://127.0.0.1:8000. See README.md for full prerequisites.
Subsequent launches: .\launch.ps1
To create the offline ZIP after building: .\package.ps1

READY-TO-RUN ZIP (WINDOWS 10/11, 64-BIT)
1. Extract the entire ZIP. Do not run files from inside the ZIP viewer.
2. Open the extracted DistriArch_CPP folder.
3. Double-click START_WINDOWS.bat and keep its console window open.
4. Open http://127.0.0.1:8000 in any modern browser.
5. Click Run simulation. Use Experiments to inspect all 81 saved runs.

No Python, Node.js, compiler, installation or internet is required to run
the included Windows executable and built dashboard. Stop with Ctrl+C
or by closing its console window.

If port 8000 is busy, use a terminal in this folder:
  build\distriarch.exe serve --root . --port 8010
Then open http://127.0.0.1:8010.
